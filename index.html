Privacy Policy

Effective date: July 29, 2026

About Rentora

Rentora is a rental property management app for landlords and property managers. It helps manage properties, tenants, rentals, and payment records.

Data Storage

Rentora stores user data locally on the device only. It does not transmit property, tenant, or rental information to any remote server.

Information Collected

The app stores the following data locally:

  • Property details (house number, rent amount, etc.)
  • Tenant details (name, phone number, ID, etc.)
  • Rental records, occupancy status, and payment history

How Data Is Used

Data is used solely to provide the app’s rental management features, such as tracking tenants, properties, and payments.

Third-Party Services

This version of the app does not use analytics, advertising, third-party trackers, or cloud syncing services.

Permissions

The app does not request special runtime permissions in release mode. It only uses local storage on the device.

Security

Data is stored on the user’s device. The owner is responsible for device security, backups, and password protection.
